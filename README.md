# Frontend Portfolio

A modern personal portfolio website built with React and Vite to showcase skills, work experience, projects, achievements, and contact details in a professional and visually engaging format.

## 🔗 Quick Links

- **Live Demo:** https://frontend-portfolio-bay-six.vercel.app/
- **GitHub Repository:** https://github.com/OletiSowmya62/frontend-portfolio

## ✨ Highlights

- ✅ Responsive personal portfolio layout
- ✅ Hero section with profile introduction and CTA buttons
- ✅ About section highlighting skills and background
- ✅ Experience timeline showcasing professional journey
- ✅ Skills section with technology stack
- ✅ Project showcase with GitHub and live demo links
- ✅ Achievements and milestones section
- ✅ Contact form with email integration
- ✅ Dark/light theme support
- ✅ Smooth animations and scroll effects
- ✅ Mobile-friendly design

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Styling:** Bootstrap, custom CSS
- **Animation:** AOS, React Type Animation
- **Icons:** React Icons
- **Form Handling:** EmailJS
- **Build Tool:** Vite
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/OletiSowmya62/frontend-portfolio.git
cd frontend-portfolio
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npm run dev
```

4. **Build for production**

```bash
npm run build
```

5. **Preview the production build**

```bash
npm run preview
```

## 🌐 Features Overview

This portfolio is designed to present a developer’s identity, technical expertise, and project work in a clear and engaging manner. It combines strong visual hierarchy, responsive layout design, and interactive elements to create an impressive online presence.
